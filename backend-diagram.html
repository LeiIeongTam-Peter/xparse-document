Request lifecycle — 7 steps every time you call the API

STEP 1
Identity Check
bustream → IAM: "Is this API key valid?" IAM returns Application + Policy data.
STEP 2
Policy Decision
Policy Kernel (pure function, zero I/O) decides: allow / deny, guardrails, rate limit.
STEP 3
Capacity Ticket
bustream acquires a lease from ResourceManager. Waits if provider is at max concurrent.
STEP 4
Route Selection
Routing library (in-process) picks the provider endpoint using the Application's strategy.
STEP 5
SSE Streaming
FAST preview → LARGE buffer → REVERSE replace → DONE. Tokens stream to client in real time.
STEP 6
Audit Record
Audit SDK writes the full event async. Tamper-evident envelope, chain-of-custody intact.
STEP 7
Release Ticket
bustream releases the capacity lease so the next waiting request in the queue proceeds.
